# openbim-xbestellung

Standard for electronic purchase orders in public procurement, for Rust. XBestellung is operated by Koordinierungsstelle für IT-Standards (KoSIT).

**Status: scaffold.** The crate states which standard it implements; reading,
writing and validating XBestellung documents are not implemented yet.

```toml
[dependencies]
openbim-xbestellung = "0.1"
```

Also available as [`@openbim/xbestellung`](https://www.npmjs.com/package/@openbim/xbestellung)
on npm and [`openbim-xbestellung`](https://pypi.org/project/openbim-xbestellung/) on PyPI.
