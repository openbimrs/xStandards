# openbim-xbau

XÖV message standard for building-permit procedures, including the XBau core module, in Python: bindings for the
[`openbim-xbau`](https://crates.io/crates/openbim-xbau) Rust crate.

**Status: scaffold.** The package states which standard it implements;
reading, writing and validating XBau documents are not implemented yet.

```python
import openbim_xbau
print(openbim_xbau.STANDARD_NAME, openbim_xbau.__version__)
```
