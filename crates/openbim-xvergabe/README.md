# openbim-xvergabe

Interface standard between e-procurement platforms and bidder tools, for Rust. XVergabe is operated by IT-Planungsrat.

**Status: scaffold.** The crate states which standard it implements; reading,
writing and validating XVergabe documents are not implemented yet.

```toml
[dependencies]
openbim-xvergabe = "0.1"
```

Also available as [`@openbim/xvergabe`](https://www.npmjs.com/package/@openbim/xvergabe)
on npm and [`openbim-xvergabe`](https://pypi.org/project/openbim-xvergabe/) on PyPI.
