# openbim-xrechnung

German CIUS of the EN 16931 electronic invoice, for Rust. XRechnung is operated by Koordinierungsstelle für IT-Standards (KoSIT).

**Status: scaffold.** The crate states which standard it implements; reading,
writing and validating XRechnung documents are not implemented yet.

```toml
[dependencies]
openbim-xrechnung = "0.1"
```

Also available as [`@openbim/xrechnung`](https://www.npmjs.com/package/@openbim/xrechnung)
on npm and [`openbim-xrechnung`](https://pypi.org/project/openbim-xrechnung/) on PyPI.
