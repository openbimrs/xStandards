# xbestellung

Short-name package for XBestellung.

This crate is a **pure re-export** of
[`openbim-xbestellung`](https://crates.io/crates/openbim-xbestellung). It defines nothing of
its own, so both package names expose one canonical API and one type identity.
The dependency is pinned to the exact canonical version.

```toml
xbestellung = "0.1"
# equivalent API to:
openbim-xbestellung = "0.1"
```
