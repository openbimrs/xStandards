# openbim-xbau

XÖV message standard for building-permit procedures, including the XBau core module, for Rust. XBau is operated by XLeitstelle Planen und Bauen.

**Status: scaffold.** The crate states which standard it implements; reading,
writing and validating XBau documents are not implemented yet.

```toml
[dependencies]
openbim-xbau = "0.1"
```

Also available as [`@openbim/xbau`](https://www.npmjs.com/package/@openbim/xbau)
on npm and [`openbim-xbau`](https://pypi.org/project/openbim-xbau/) on PyPI.
