# xvergabe

Short-name package for XVergabe.

This crate is a **pure re-export** of
[`openbim-xvergabe`](https://crates.io/crates/openbim-xvergabe). It defines nothing of
its own, so both package names expose one canonical API and one type identity.
The dependency is pinned to the exact canonical version.

```toml
xvergabe = "0.1"
# equivalent API to:
openbim-xvergabe = "0.1"
```
