# openbim-xtrasse

Geodata standard for planned line routes, built on XPlanung, for Rust. XTrasse is operated by XLeitstelle Planen und Bauen.

**Status: scaffold.** The crate states which standard it implements; reading,
writing and validating XTrasse documents are not implemented yet.

```toml
[dependencies]
openbim-xtrasse = "0.1"
```

Also available as [`@openbim/xtrasse`](https://www.npmjs.com/package/@openbim/xtrasse)
on npm and [`openbim-xtrasse`](https://pypi.org/project/openbim-xtrasse/) on PyPI.
