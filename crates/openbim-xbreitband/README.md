# openbim-xbreitband

XBau specialist module for permits in broadband rollout and civil works (XBau-Tiefbau), for Rust. XBreitband is operated by XLeitstelle Planen und Bauen.

**Status: scaffold.** The crate states which standard it implements; reading,
writing and validating XBreitband documents are not implemented yet.

```toml
[dependencies]
openbim-xbreitband = "0.1"
```

Also available as [`@openbim/xbreitband`](https://www.npmjs.com/package/@openbim/xbreitband)
on npm and [`openbim-xbreitband`](https://pypi.org/project/openbim-xbreitband/) on PyPI.
