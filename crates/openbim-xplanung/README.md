# openbim-xplanung

Exchange standard for spatial and land-use plans (XPlanGML), for Rust. XPlanung is operated by XLeitstelle Planen und Bauen.

**Status: scaffold.** The crate states which standard it implements; reading,
writing and validating XPlanung documents are not implemented yet.

```toml
[dependencies]
openbim-xplanung = "0.1"
```

Also available as [`@openbim/xplanung`](https://www.npmjs.com/package/@openbim/xplanung)
on npm and [`openbim-xplanung`](https://pypi.org/project/openbim-xplanung/) on PyPI.
