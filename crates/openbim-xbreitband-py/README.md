# openbim-xbreitband

XBau specialist module for permits in broadband rollout and civil works (XBau-Tiefbau), in Python: bindings for the
[`openbim-xbreitband`](https://crates.io/crates/openbim-xbreitband) Rust crate.

**Status: scaffold.** The package states which standard it implements;
reading, writing and validating XBreitband documents are not implemented yet.

```python
import openbim_xbreitband
print(openbim_xbreitband.STANDARD_NAME, openbim_xbreitband.__version__)
```
