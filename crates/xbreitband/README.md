# xbreitband

Short-name package for XBreitband.

This crate is a **pure re-export** of
[`openbim-xbreitband`](https://crates.io/crates/openbim-xbreitband). It defines nothing of
its own, so both package names expose one canonical API and one type identity.
The dependency is pinned to the exact canonical version.

```toml
xbreitband = "0.1"
# equivalent API to:
openbim-xbreitband = "0.1"
```
